# Навчальний стенд M4 · AI-асистент у коді автотестів

Стенд курсу Mate Academy «AI-інструменти для QA», модуль M4. Сторінки потрібні для
запису трьох відео: `M4T2-video-1`, `M4T2-video-2`, `M4T2-video-3`. Продукти вигадані,
дані вигадані, бекенду немає — це статичні сторінки.

## НЕ ВИПРАВЛЯТИ

На сторінках є два місця, які виглядають як помилка і нею не є.

1. У `parcelo/parcels/UA123456789/` позначка `delay-badge` видима, хоча статус посилки —
   `customs_hold`. За специфікацією продукту в цьому стані відлік SLA зупинений і позначки
   бути не повинно. Це навмисний дефект: на ньому стоїть уся демонстрація у `M4T2-video-2`.
2. У `taskline-mcp/` поле email підписане «Work e-mail», а не «Email». Розбіжність навмисна:
   на ній стоїть порівняння у `M4T2-video-3`.

Підписи полів, значення `data-testid` і тексти статусів не міняти без узгодження з автором
курсу. Будь-яка «косметична» правка тут ламає сценарій запису.

## Маршрути

```
taskline/       → /login, /dashboard        поле підписане "Email"
taskline-mcp/   → /login, /dashboard        поле підписане "Work e-mail"
parcelo/        → /parcels/UA123456789      стан сторінки після релізу
```

Облікові дані для входу на обох варіантах логіну: `qa.tester@example.com` / `Str0ng!Pass99`.
Будь-яка інша пара показує над формою повідомлення `Invalid email or password`.

## Розміщення

Усі три теки лежать в одному репозиторії й віддаються одним сайтом GitHub Pages з кореня
гілки `main`. Адреси виходять такі:

```
https://<організація>.github.io/qa-ai-demo-m4/taskline/login
https://<організація>.github.io/qa-ai-demo-m4/taskline-mcp/login
https://<організація>.github.io/qa-ai-demo-m4/parcelo/parcels/UA123456789
```

У Playwright-проєкті базова адреса має включати теку, а шлях у тесті пишеться без слеша на
початку: `page.goto('login')`. Зі слешем — `page.goto('/login')` — браузер відкине префікс
`/qa-ai-demo-m4/taskline` і піде на корінь домену.

Перехід на дашборд робиться через `history.pushState`, тому адреса закінчується рівно на
`/dashboard` без слеша — саме це потрібно для `page.waitForURL('**/dashboard')`. Теки
`dashboard/` покладені для того, щоб пряме відкриття адреси теж працювало.

У кожному файлі стоїть `<meta name="robots" content="noindex">`. Порожній `.nojekyll` у
корені репозиторію вимикає обробку Jekyll.
